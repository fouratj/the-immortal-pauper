## QUERYING STRATEGY

- **Batch size:** Send 5-8 queries at a time, then wait for responses before sending more
- **Personalization:** Tailor the comp line and opening for each agent. The current letter leads with Hawkins/Stephenson — adjust for agents who don't rep Hawkins
- **Track everything:** Use QueryTracker to log sent dates, response times, and outcomes
- **Word count flag:** At 65,000 words, some agents may hesitate. Consider expanding before querying widely, or be prepared to discuss expansion plans if an agent asks
- **Subject line format:** "Query: THE HEIR CONDITION — Science Fiction, 65,000 words" (unless agent specifies otherwise)
- **One agency at a time:** Most agencies ask you query only one agent per agency. After a pass, you can query another at the same agency.
